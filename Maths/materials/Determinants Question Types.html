Systems with no solution or a unique solution (Type 1) alone are 38 questions (26%). About 12% of the questions ask for a numerical (integer) answer, so there are no options to guess from.

How to read this: a “type” is the formula, law or technique that decides the answer. So every type below tells you what the question looks like and which formula or method to use.

3. Type-by-type detail

Type 1: No solution, unique solution, consistency and nature of solutions – 38 questions

What is asked: Decide for which values of the parameters a 3×3 system has no solution, a unique solution or is consistent, or pick the correct (or NOT correct) statement about its solutions.

What to master: Δ ≠ 0 ⇒ unique solution; Δ = 0 with Δx, Δy or Δz ≠ 0 ⇒ no solution; Δ = Δx = Δy = Δz = 0 ⇒ infinitely many or none (check the rank); the augmented matrix after row operations.

Forms that appear: the number of values of λ for which the system has no solution, consistent for all k in a set, (a,b) for which there is no solution, which one of the following is NOT correct, the nature of x + y + z = 6 style systems.

Asked in: 2019 (5), 2020 (4), 2021 (10), 2022 (7), 2023 (9), 2024 (2), 2025 (1)

Which form was asked:

Find the parameter, or the number of values, for which the system has no solution, a unique solution or is inconsistent: 18 questions

Nature of the solution: which statement is correct or NOT correct, and what the system has: 20 questions

Type 2: Infinitely many solutions: find the parameters – 36 questions

What is asked: Use the condition that a system has infinitely many solutions to find the unknown constants and then a combination such as λ + μ or 2a + 3b.

What to master: Δ = 0 and Δx = Δy = Δz = 0; the third equation is a combination of the first two; elimination to reduce the system; ranks of the coefficient and augmented matrices are equal and less than 3.

Forms that appear: x + y + z = 5 style systems with λ and μ and λ + μ asked, 2a + 3b, α and β given as roots of a quadratic, (λ, μ) as an ordered pair, 13αβ, α + β + 2.

Asked in: 2019 (3), 2020 (5), 2021 (4), 2022 (4), 2023 (5), 2024 (8), 2025 (7)

Which form was asked:

Infinitely many solutions: find the two parameters and a simple combination of them: 28 questions

Infinitely many solutions: ordered pair, a root of an equation or another quantity: 8 questions

Type 3: Homogeneous systems with a non-trivial solution – 16 questions

What is asked: A homogeneous system is given and a parameter (or an expression in x, y, z) is to be found when it has a non-trivial solution.

What to master: A homogeneous system has non-trivial solutions ⇔ Δ = 0; ratios x : y : z from two equations; the trivial solution always exists.

Forms that appear: the greatest value of c for non-trivial solution, 6α + 9β + 7γ with a row vector times a matrix, sin α and cos α coefficients, k from x + y + z type homogeneous systems, a sum of distinct values of λ.

Asked in: 2019 (4), 2020 (4), 2021 (4), 2023 (2), 2024 (2)

Type 4: Systems linked to geometry, counting or matrices – 16 questions

What is asked: Use a system with parameters together with a distance, a circle, collinear points, integer solutions or a matrix relation.

What to master: Distance of a point from a plane |ax₁ + by₁ + cz₁ + d|/√(a² + b² + c²); equation of a circle touching a line; collinearity; AX = λX; (A − kI)X = B.

Forms that appear: distance of (λ, μ, −1/2) from a plane, the radius of the circle centred at (λ, μ) touching 4x = 3y, collinear points (α, x*), (y*, α), (x*, −y*), integer solutions with 15 ≤ x² + y² + z² ≤ 150, A − 3I with given eigenvectors.

Asked in: 2019 (1), 2020 (2), 2021 (2), 2022 (4), 2023 (2), 2024 (3), 2025 (2)

Type 5: Evaluating and solving determinants by properties – 16 questions

What is asked: Evaluate a 3×3 determinant, prove an identity or solve Δ = 0 using row and column operations and the factor theorem.

What to master: Row and column operations; taking out common factors; a determinant with two identical rows is 0; Δ = 0 at x = a ⇒ (x − a) is a factor; expansion along a row.

Forms that appear: determinant with arithmetic-progression entries, Δ = (a + b + c)(x + a + b + c)², roots of Δ = 0, the sum of the real roots, matrix with entries a_r = cos(2rπ/9) + i sin(2rπ/9).

Asked in: 2019 (5), 2020 (3), 2021 (4), 2023 (2), 2024 (2)

Type 6: Determinant as a function of x or θ – 16 questions

What is asked: A determinant with variable entries defines f(x): find its maximum, minimum, range, derivative, limit or a sum.

What to master: C₁ → C₁ + C₂ + C₃ reduces f(x) to a simple function; range of sin, cos; f′(x) by differentiating one row at a time; Σk, Σk² for a sum over k.

Forms that appear: the maximum and minimum of a determinant with 1 + sin²x entries, f′(0), the minimum value of det(A)/b, the sum of the local maximum and local minimum values of a cubic, ∑ D_k = 96.

Asked in: 2019 (3), 2020 (2), 2021 (3), 2022 (1), 2023 (2), 2024 (2), 2025 (3)

Type 7: Special determinants: scaling, row operations, factorials, [x] and logarithms – 8 questions

What is asked: A determinant whose rows or entries are scaled, operated on, or built from factorials, the greatest integer function or logarithms.

What to master: |kA| = kⁿ|A|; R₂ → 2R₂ + 5R₃ multiplies |A| by 2; (p + 2)! = (p + 2)(p + 1)p!; [x + n] = [x] + n; log(ab) = log a + log b; |AB| = |A||B|.

Forms that appear: R₂ → 2R₂ + 5R₃ on 2A, det(BA⁻¹Bᵀ) from det(ABAᵀ) and det(AB⁻¹), factorial matrix and prime powers p^α and (p + 2)^β, A_r sums.

Asked in: 2019 (3), 2020 (1), 2021 (2), 2022 (1), 2024 (1)

5. Suggested study order for students

Start with systems of linear equations (Types 1 and 2): 74 questions (51%). Master the Δ, Δx, Δy, Δz rule and the row-reduction check.

Then homogeneous systems and systems combined with geometry (Types 3 and 4): 32 questions (22%).

Then evaluating determinants, determinants as functions and special determinants (Types 5, 6 and 7): 40 questions.

6. A routine to follow for every question

Read whether the system is homogeneous and which condition is asked: unique, no solution, infinitely many or non-trivial.

Write the coefficient matrix and find Δ as a function of the parameter; the special values of the parameter come from Δ = 0.

For each special value, reduce the augmented matrix (or find Δx) to decide between no solution and infinitely many.

For determinants with variable entries, use row and column operations to take out common factors before expanding.

Check the answer by substituting the parameter values back into the original equations.
